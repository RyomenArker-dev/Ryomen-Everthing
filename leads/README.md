# Lead management

Process and rubric for finding and qualifying prospects. **Real lead data lives in
`leads/data/` and is git-ignored.**

- Process: [sops/lead-research.md](../sops/lead-research.md)
- Qualification rubric: [qualification-rubric.md](qualification-rubric.md)
- Pipeline columns: [templates/lead-pipeline.csv](../templates/lead-pipeline.csv) — copy to
  `leads/data/pipeline.csv` to start.
- One record per lead: [templates/lead-record.md](../templates/lead-record.md)

Rules: only public, business-level information; every fact has a source URL and a checked date;
no scraping that breaks a site's terms; no outreach is ever sent without approval.
