# SOP: Brand identity project

| Field | Value |
|---|---|
| Trigger | Brand service in scope |
| Owner | brand-designer, QA by quality-analyst |
| Outputs | `clients/<slug>/brand/` — brief, directions, guidelines, tokens.css |
| Approval points | Direction choice, final guidelines, any paid design tool |
| Last reviewed | 2026-11-03 |

## Steps
1. Brand brief from `templates/brand-brief.md` (skill `ryomen-brand-identity`).
2. Competitor visual audit (sourced, no copying).
3. 2–3 directions with palette + computed contrast + licensed fonts.
4. Client choice → `log.md`.
5. Refine; produce guidelines and `tokens.css`; export logo SVG/PNG (owner/designer tool).
6. QA → approval gate → owner delivers files.

## Common mistakes
Unlicensed fonts · low contrast palettes · imitating a famous brand · skipping the brief.
