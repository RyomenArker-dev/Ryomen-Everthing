# SOP: SEO audit

| Field | Value |
|---|---|
| Trigger | SEO service, or website project start |
| Owner | marketing-strategist, QA by quality-analyst |
| Outputs | `clients/<slug>/docs/YYYY-MM-DD-seo-audit.md` |
| Approval points | Any change to the live site or Google profiles |
| Last reviewed | 2026-11-03 |

## Steps
1. Scope: domain, priority pages, target location, services.
2. Technical: fetch pages (WebFetch) — titles, meta descriptions, headings, canonical, robots.txt,
   sitemap.xml, HTTPS, mobile viewport, image alt text. Record URL + date for each finding.
3. Performance: owner runs PageSpeed Insights (free) and shares results — mark `NOT PROVIDED` otherwise.
4. Local: Google Business Profile presence (public view) — completeness observations.
5. Content: topics vs. services; gaps. Keyword volumes only from a cited tool export, else omit.
6. Prioritised actions: impact / effort / owner. No ranking guarantees.
7. Use third-party `seo-audit`, `ai-seo`, `schema` skills for depth. QA → approval gate.
