# Agency operations

Your agency's own operating information. These files are tracked in git (they are about *your*
business, not about clients). They start as placeholders — **Claude must not invent your prices,
results or credentials.** Fill them in with the `business-strategist` agent.

| File | What it holds |
|---|---|
| [services.md](services.md) | Service catalogue: what you deliver, scope, timeline, price placeholders |
| [pricing.md](pricing.md) | Pricing model, rates, payment terms |
| [positioning.md](positioning.md) | Who you serve, why you, differentiators |
| [tools-register.md](tools-register.md) | Every tool/service used, cost, account owner, approval status |
| [policies.md](policies.md) | Approvals, data handling, revisions, cancellations |
