# Templates

Reusable starting points. Copy into the right client folder — never edit a template in place for a
single client. Placeholders: `{{like_this}}` are filled by scripts; `TODO:` lines need a human.

| Template | Used by |
|---|---|
| [client-intake.md](client-intake.md) | onboarding questionnaire |
| [project-charter.md](project-charter.md) | project kick-off |
| [proposal.md](proposal.md) | `scripts/new_proposal.py`, `ryomen-proposal` |
| [brand-brief.md](brand-brief.md) | brand-designer |
| [website-brief.md](website-brief.md) | web-developer, copywriter |
| [campaign-plan.md](campaign-plan.md) | marketing-strategist |
| [monthly-report.md](monthly-report.md) | `ryomen-report` |
| [lead-record.md](lead-record.md), [lead-pipeline.csv](lead-pipeline.csv) | lead-researcher |
| [approval-request.md](approval-request.md) | `ryomen-approval-gate` |
| [qa-checklist.md](qa-checklist.md) | quality-analyst |
| [sop-template.md](sop-template.md) | writing new SOPs |
