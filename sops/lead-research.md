# SOP: Lead research

| Field | Value |
|---|---|
| Trigger | Owner wants new prospects for a service/niche/location |
| Owner | lead-researcher |
| Outputs | `leads/data/*.md`, `leads/data/pipeline.csv` (git-ignored) |
| Approval points | Any outreach message |
| Last reviewed | 2026-11-03 |

## Steps
1. Define: niche, location, service, number of leads.
2. Search public sources; open each candidate page.
3. Record facts with URL + date (`templates/lead-record.md`). Unknown stays UNKNOWN.
4. Score with `leads/qualification-rubric.md`.
5. Add pipeline row; summarise top leads to owner.
6. Optional outreach draft → approval gate → owner sends personally.

## Common mistakes
Guessing emails · inferring owner names · copying private data · scoring without evidence ·
breaking site terms or local anti-spam laws (owner is responsible for compliance when sending).
