# SOP: Client offboarding

| Field | Value |
|---|---|
| Trigger | Project complete or retainer ends |
| Owner | Owner |
| Outputs | Handover pack, final report, archived folder |
| Approval points | Final message; data deletion |
| Last reviewed | 2026-11-03 |

## Steps
1. Handover: files, logins transferred via role changes (client keeps ownership of domains/accounts).
2. Final report (`ryomen-report`) and testimonial request draft → approval gate.
   Testimonials are used only with written permission and exactly as given.
3. Remove agency access from client accounts (owner).
4. Archive or delete client data per agreement — deletion needs owner approval.
5. Update `log.md` status `closed`.
